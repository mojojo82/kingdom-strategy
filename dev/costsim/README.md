# Firebase cost calculator (v1625)
- `node dev/costsim/calc.js` - reads/writes/server calls a day and $ a month for 100 / 1,000 / 10,000 / 100,000 daily players, today vs "event rewards paid by the server".
- Input 1: `session_profile.json` - a measured headless player session (sign-up, 3 min Conquest, 1 min World map, upgrades, events + claim, 2 Arena results, alliance + chat, 2 min idle). Counters: dev/tests/fakefb.js (`window.__fbStats`, billing-like: listener = 1 read per changed doc) and dev/tests/fnrunner.js (`.stats`, server reads/writes). Re-measure: the scratch script cost_session.js pattern (map_mock harness + snapshots of the counters per segment).
- Input 2: the ASSUMPTIONS block in calc.js (sessions a day, minutes per screen, claims, chat, kingdom size, online share, Alliance Siege). Fan-out from OTHER players (chat, map changes, siege) is estimated, the fake store can't measure it.
- Prices (Nov 2026): Firestore Standard us-central1 $0.03 / 100K reads, $0.09 / 100K writes, free 50K reads + 20K writes a day; Cloud Run functions $0.40 / million calls (2M free a month) + $0.000024 per vCPU-second (180K free) - a multi-region database costs about 2x for reads/writes.
