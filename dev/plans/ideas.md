# Ideas for consideration (Harley, 17 Oct 2026)

Features the game doesn't have yet that would be fairly easy to add. Nothing here is decided - Harley picks when he wants one.
(Checked against the TEST game v1226: none of these exist yet. There is already a plan for Achievements in dev/plans/achievements.md.)

## Small (an hour or two each)
1. **Daily login rewards** - 7-day calendar, day 7 gives something good, missing a day resets the streak. Reason to open the game every day.
2. **Daily tasks** - e.g. "Train 500 troops", "Win 3 Arena fights", "Kill 5 monsters". Each ticks off for a small reward, plus a chest when all are done. Everything they track already exists.
3. **Peace shield** - item or gem buy that stops anyone attacking your base for 8 / 24 h (ends if you attack). New players could get a free one for their first days.
4. **Gift codes** - Harley makes a code (e.g. LAUNCH2026) in the admin panel, players type it in for rewards. For testers / Discord / promos. Can ride on the existing mail system.
5. **"Ready" badges** - red dot on City / Heroes etc. when something can be collected or a build finished.

## Medium (half a day to a day)
6. **Alliance help** - teammates tap "Help" on each other's builds / research / healing, each tap takes some time off (big reason to stay in an alliance in Kingshot).
7. **Real Power leaderboard** - top players and alliances by power from real accounts on the server (the Arena board today uses made-up names).
8. **Phone notifications** - "troops finished", "base under attack" (works when the game is saved to the phone's home screen).
9. **Guided first 10 minutes** - a pointer that walks new players through build, train, first Conquest fight, first march.

## Bigger (later)
10. **Season pass** - free + paid reward track levelled by daily tasks (needs 2 first). The most common way these games make money.

My suggested order if/when: 2 (daily tasks), then 1 (login rewards) - testers get something to do every day and the rest hooks into them.
