🛒 Shop & packs

Make each pack once in the library, then place it in shop tabs (Deals, Shop…). Packs ticked 🎁 also appear in the mail boxes' gift picker. Everything here belongs to the selected environment (test or live). Payments aren't connected yet, so players see the shop with a "coming soon" buy button.

Each tab is a row of packs in the order players see them. Optional start/end times make timed deals (they appear and disappear by themselves); a badge shows on the pack (e.g. "-50%", "Best value").
Every purchase gives top-up points (set per price tier). Each ladder adds them up over its period - daily, weekly, monthly (reset 00:00 UTC; weeks start Monday), lifetime, or an event between two dates - and players claim a reward at each milestone. Gems go straight to the player; other items arrive by mail.
One row per price tier; each pack picks a tier. Change a row and every pack on that tier changes. Tier 0 = free. The MXN / EUR / TRY numbers were filled in as rough suggestions - check them (Turkish lira prices usually need a refresh every few months).

🎉 Events

Goal events with a reward at each milestone; the last milestone is the grand prize (shown on top, like Burst of Life). "New players" events run for each player from the day their account was made; dated events run for everyone between two dates. Progress is checked by the server against the player's saved game.

📦 Import a save into my account

For moving your old claude.ai save into Firebase. Pick the save file, check the summary, then Import. It goes into your own account in the environment selected above. Your current save is backed up first. Your kingdom, map position and marches are kept from your current account (the old map no longer exists). Close the game on every device first, then open it again after importing.

🛠️ Maintenance mode

While ON, players in the selected environment see a maintenance screen and nothing they do is saved; the server refuses their saves and claims. You (admin) can still play. Turning it OFF reloads everyone's game onto the newest version.
